## What to implement

### 1. Create `src/extraction-worker/routes/extract.ts`

A POST handler at `/profile-runner/extract` that:

**THIS IS THE TRUSTED EXTRACTION PATH. Critical rules:**
- NEVER call an LLM or AI agent
- NEVER fall back to generic extraction if profile selectors fail
- NEVER guess variant selection — it must be deterministic
- ALWAYS return `ok: false` rather than untrusted data
- ALWAYS record fieldProvenance for every extracted field
- ALWAYS validate output against ExtractionDataSchema

**Execution flow:**

1. Parse and validate the request body against `ExtractRequestSchema`
2. Determine runtime from `request.profile.runtime` ('static' or 'rendered')
3. Fetch the page:
   - Static: `fetch` with HTTP_EXTRACTION_HEADERS, timeout 15s, parse with cheerio
   - Rendered: launch Playwright, block images/fonts/styles/trackers, navigate with 25s timeout, dwell 2s
4. For static runtime:
   - Use cheerio to load the HTML
   - Apply each selector from `request.profile.selectors`:
     - titleSelector → `$(selector).first().text().trim()`
     - priceSelector → `$(selector).first().text().trim()`
     - descriptionSelector → `$(selector).first().text().trim()`
     - brandSelector → `$(selector).first().text().trim()`
     - imagesSelector → collect all matching element image sources (src/srcset/data-src) using `collectImageSourcesFromElement` pattern, deduplicate
   - Extract JSON-LD from `<script type="application/ld+json">` tags
   - Extract meta tags (og:*, product:*, description)
5. For rendered runtime:
   - Evaluate each selector in the browser via `page.evaluate`
   - Extract JSON-LD from page scripts
   - Extract embedded product data (window.productJSON, variants)
6. Apply expected data:
   - Override price with `expected.price` if provided (the Bun server brings spreadsheet price)
   - Mark price provenance as "spreadsheet-import"
7. Build `ExtractionData`:
   - title from titleSelector
   - brand from brandSelector
   - description from descriptionSelector
   - price from expected.price or priceSelector
   - primaryImage from images (first image is primary, rest are additional)
   - sourceUrl from the request
   - confidence from how many required fields were extracted
   - fieldProvenance tracking where each field came from ("profile-selector")
8. If any profile selector returns empty for a required field, add a warning but still return what we got
9. If titleSelector returns empty → return `ok: false` (title is mandatory)
10. Parse through `ExtractionDataSchema` and return via `ExtractResponseSchema`
