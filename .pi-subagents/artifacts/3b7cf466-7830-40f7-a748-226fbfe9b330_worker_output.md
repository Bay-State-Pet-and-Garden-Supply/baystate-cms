### What the implementation does

1. **Request parsing & validation** — Parses JSON body, validates against `ExtractRequestSchema`, returns 400 with field-level errors on failure.

2. **Runtime dispatch** — `static` (HTTP fetch + Cheerio) or `rendered` (Playwright headless Chromium), governed by `request.profile.runtime`.

3. **Static path:**
   - Fetches page with standard HTTP headers, 15s timeout, redirects followed.
   - Loads HTML with Cheerio.
   - Applies profile selectors (`titleSelector`, `brandSelector`, `descriptionSelector`, `priceSelector`, `imagesSelector`) via `$(selector).first().text().trim()`.
   - Extracts JSON-LD Product blocks, meta tags (og:*, product:*, description), and microdata as supplementary fallback sources.
   - Collects image sources from `imagesSelector`-matched elements using the `collectImageSourcesFromElement` pattern (src, data-src, data-original, srcset scanning, SVG/data/blob filtering, dedup, absolute URL resolution).

4. **Rendered path:**
   - Launches Playwright headless Chromium with resource blocking (images, fonts, stylesheets, media, trackers).
   - Navigates with `waitUntil: 'domcontentloaded'`, 25s timeout, 2s dwell.
   - Evaluates text selectors via `page.evaluate()`, collects images via inline IIFE string (avoids tsx runtime injection issues).
   - Extracts JSON-LD, meta tags, and embedded Shopify data (`productJSON`, `ShopifyAnalytics`, `__INITIAL_STATE__`).

5. **Fallback chain** — For each field: selector value → JSON-LD → meta tags → microdata. Title being empty after all fallbacks → `ok: false`.

6. **Price override** — `expected.price` overrides any extracted price with provenance `"spreadsheet-import"`.

7. **Output validation** — All extractions pass through `ExtractionDataSchema.parse()`, response through `ExtractResponseSchema.parse()`.

8. **Error handling** — All errors surface in the `warnings` array; uncaught exceptions return a minimal `ExtractResponse` with `ok: false`. Never throws uncaught errors.

### Critical rules enforced
- ✅ No LLM calls
- ✅ No generic fallback (cheerio/Playwright extraction only uses profile selectors + same-page structured data)
- ✅ No variant guessing (deterministic selector-based only)
- ✅ Title mandatory → `ok: false` when empty
- ✅ Every field has tracked provenance
- ✅ All output validated through Zod schemas
