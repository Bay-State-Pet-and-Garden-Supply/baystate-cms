# Task for worker

## Task B1: Create ProfileExtractionPreview component

Create `src/client/components/ProfileExtractionPreview.tsx` — a preview-driven review panel that shows extracted product data instead of CSS selectors.

Read these for reference:
- `src/client/components/ImagePreviewGrid.tsx` — existing image grid component
- `src/client/components/ProfileBuilderWorkspace.tsx` — for pill/section styling patterns
- `src/shared/schemas/onboarding.ts` — no new schemas needed, this is a pure presentational component

### Component

```tsx
import React from 'react';
import { ImagePreviewGrid } from './ImagePreviewGrid';

interface SeedPreviewData {
  title: string | null;
  description: string | null;
  images: string[];
  variantOptions: string[];
  strategy: 'shopify-json' | 'css';
  variantSelectionStrategy: {
    containerSelector: string | null;
    optionType: string | null;
    detectedOptions: string[];
    optionFields: string[];
  } | null;
}

interface ProfileExtractionPreviewProps {
  seedPreview: SeedPreviewData | null;
  sourceUrl: string;
  onDemandResult?: {
    title?: string | null;
    description?: string | null;
    images?: string[];
    variantOptions?: string[];
  } | null;
  busy?: boolean;
}
```

### Rendering logic

**Loading state**: When `busy` is true, show a simple "Loading preview..." message with a spinner-like indicator (a pulsing dot).

**No data state**: When both `seedPreview` and `onDemandResult` are null/empty, show: "No preview available. Generate a proposal first." with a small note linking to the seed URL.

**Main preview** (when data is available):

Use data from `seedPreview` first, falling back to `onDemandResult` for fields that are null.

1. **Strategy badge** — A small badge in the top-right showing the strategy: "Shopify JSON" (blue) or "CSS Selectors" (gray). Use `strategy` from seedPreview.

2. **Title** — The extracted title in a large bold font (18px, semibold). If null/empty, show "—" in gray.

3. **Description** — The extracted description in a paragraph (14px). Clamp to 4 lines with `WebkitLineClamp`. If null/empty, hide the section.

4. **Image thumbnails** — Render the `ImagePreviewGrid` component with the extracted images array. Use compact mode with `maxImages={8}`. If no images, show a small gray "No images extracted" text.

5. **Variant options** (if `variantOptions.length > 0`) — Show as a row of pills/badges, matching the style from `ProfileBuilderWorkspace.tsx`:
   ```
   Variant options: [Small] [Medium] [Large]
   ```
   If coming from seedPreview's `variantSelectionStrategy.detectedOptions`, label them "Detected options:" instead.

6. **Variant strategy** (if `seedPreview.variantSelectionStrategy` exists and is non-null) — Show a small subsection:
   - Container selector as `<code>` text
   - Option type badge
   - Detected options as pills

### Styling
- Use inline styles matching the existing Project onboarding components
- The container should have a white background, 12px border-radius, 16px padding, subtle border
- Title: `fontSize: 18, fontWeight: 600, marginBottom: 8`
- Description: `fontSize: 14, lineHeight: 1.5, color: '#555'`
- Section headers (like "Variant options"): `fontSize: 12, fontWeight: 600, textTransform: 'uppercase', color: '#888', marginBottom: 4`
- Pills: follow `ProfileBuilderWorkspace`'s pill style: `padding: '2px 8px', borderRadius: 12, fontSize: 12, background: '#e9ecef', display: 'inline-block', marginRight: 4`

### Acceptance
- Component renders title/description/images/variantOptions from seedPreview with no network calls
- Falls back to onDemandResult when seedPreview is null
- Image thumbnails use ImagePreviewGrid component
- Strategy badge shows correct strategy name and color
- No price, brand, or selector strings shown
