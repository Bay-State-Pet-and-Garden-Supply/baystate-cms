# Scope domain extractor profiles to page structures

Some brand domains use multiple product-page structures, so a single domain-wide extractor profile would either become too generic or fail validation on legitimate pages. We decided that a domain may have multiple Domain Extractor Profiles, each scoped to the subset of product pages it covers, and that Profile Health applies to the matched profile rather than to the whole domain. A Profile Scope is defined by both an operator-visible URL pattern and a page-structure signal, so a profile does not silently apply to a redesigned or mismatched template. Extraction chooses the most specific healthy matching profile, fails closed when no healthy profile matches, and requires operator resolution when multiple equally specific profiles match. If a URL matches but the page-structure signal no longer matches, Extraction fails closed for that item and creates a revalidation requirement without immediately invalidating the whole profile. Generic HTTP or browser extraction may still run as Profile Tooling Extraction for generation, validation, previews, and diagnostics, but it cannot produce trusted product evidence. The Profile Builder may use LLM-assisted browser extraction to draft profiles, but it remains proposal-only; validation and reviewer approval are required before Profile Health can allow automated Extraction. Variant-bearing profiles handle source-page variant selection for one imported Product SKU, not full product-family modeling; the builder may propose the selection strategy, but automated Extraction executes it deterministically and fails closed on ambiguity. Profile building is domain-first: item-level failures can deep-link into the domain's builder workspace as seed samples, but profile review is not a one-off product drawer flow. Sitemap-discovered product URLs can help exploration, but only confirmed profile samples count toward Profile Health. When a profile becomes healthy, affected profile-blocked items are not rerun automatically; reviewers see a retry preview and queue selected items.
